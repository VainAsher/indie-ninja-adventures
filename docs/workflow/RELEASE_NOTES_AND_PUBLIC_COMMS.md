# Release Notes and Public Comms Workflow

Use this workflow for player-facing release communication.

## Canonical Loop

1. Ensure release-facing changes are captured in `CHANGELOG.md`.
2. Decide whether `DEVLOG.md` entry is required.
3. Sync cross-repo public notes ownership (launcher/docs pages as needed).
4. Publish notes only after release gates are green.
