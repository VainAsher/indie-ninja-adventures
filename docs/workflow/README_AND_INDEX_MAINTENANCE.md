# README and Index Maintenance Workflow

Use this workflow when docs routes or canonical ownership change.

## Canonical Loop

1. Update `docs/INDEX.md` routing first.
2. Update `README.md` summary pointers if top-level docs changed.
3. Confirm links resolve and stale pointers are archived or removed.
4. Record major routing changes in decision records when needed.
