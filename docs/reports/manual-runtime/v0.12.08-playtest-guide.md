# Playtest Guide — v0.12.08

**Focus:** Six stance/duality systems shipped this build. Each section below tells you what to do, what to look for, and what to note if something feels wrong.

---

## Setup

1. Launch from `python launcher/launcher.py`
2. Confirm the version badge reads **v0.12.08**

## Slice 1 — Stance-Driven Movement Feel

**What changed:** Run speed, dash distance, and wall-jump horizontal kick now scale by stance.

| Stance | Run | Dash | Wall-jump X |
|--------|-----|------|-------------|
| Yin    | −15 % | −10 % | −10 % |
| Yang   | +15 % | +15 % | +15 % |
| Flow   | +5 % | +5 % | +5 % |

### Steps

1. Switch to **Yin** stance. Run across a long platform. Note that movement feels deliberate and slightly slow.
2. Switch to **Yang** stance. Run the same stretch. Should feel noticeably faster and more aggressive.
3. Perform a dash in each stance — Yang dash should cover more ground.
4. Wall-jump in each stance — Yang should kick you further horizontally.

### Report

- [ ] Yin feels slower (good). Yang feels faster (good).
- [ ] Dash distance difference is perceivable but not broken (doesn't fly through geometry).
- [ ] Wall-jump kick difference is perceivable.

## Slice 2 — Noise Emission + Enemy Awareness

**What changed:** Dashing, attacking, throwing shurikens, and landing hard all emit noise. Enemies transition `UNAWARE → SUSPICIOUS → ALERTED → SEARCHING`.

Yang dash emits more noise than Yin dash. Yang attack emits more noise than Yin.

### Steps

1. Stand still in a room with an enemy. Do nothing — enemy should stay UNAWARE and not react.
2. Perform a **Yang dash** near (but not in line-of-sight of) an enemy. Enemy should enter SUSPICIOUS state (may look around or pause).
3. Perform a **Yang melee attack** close to an enemy — should escalate to ALERTED.
4. Try the same sequence in **Yin** stance — noise threshold is lower; takes more actions to alert the same enemy.
5. Wait without acting after alerting — enemy should return to SEARCHING then UNAWARE over time.

### Report

- [ ] Yang dash near enemy causes reaction, Yin dash less so.
- [ ] Attack near enemy escalates awareness.
- [ ] Enemy eventually de-escalates if you go quiet.
- Enemy felt too sensitive (alerts from too far away):
- Enemy felt too deaf (no reaction even when expected):
- Any enemies stuck in ALERTED permanently:

## Slice 3 — Phase Teleport Stance Variants

**What changed:** Teleport type is now resolved at the moment you trigger it:

| Stance | Teleport | Effect |
|--------|----------|--------|
| Yin    | ShadowStep | Silent, 10 % longer cooldown |
| Yang   | ThunderStep | Emits loud noise, stuns enemies within 96 px radius for 0.8 s, 40 % longer cooldown |
| Flow   | HarmonicStep | No noise, 40 % shorter cooldown |

### Steps

1. In **Yin** stance, teleport next to an enemy — enemy should NOT be stunned, and you should arrive silently.
2. In **Yang** stance, teleport directly on top of or adjacent to an enemy — enemy should be briefly stunned (frozen/grey out / pause AI).
3. In **Flow** stance (balance Yin/Yang then act quickly), teleport — should feel snappier (shorter cooldown before you can teleport again).
4. Check that you cannot spam teleport in Yang (longer cooldown should be noticeable).

### Report

- [ ] ShadowStep arrives silently, no enemy stun.
- [ ] ThunderStep stuns nearby enemies.
- [ ] HarmonicStep has visibly shorter cooldown.

## Slice 4 — Echo Art Stance Types

**What changed:** When you spawn an Echo of yourself, the type is resolved from your current stance:

| Stance | Echo Type | Effect |
|--------|-----------|--------|
| Yin    | Silent Echo | No noise, stealthy replay |
| Yang   | Riot Echo | Emits a burst of noise on spawn (enemies may react) |
| Flow   | Resonant Echo | No noise, flow-optimised |

### Steps

1. In **Yang** stance, spawn an Echo in a room with enemies nearby — enemies should react to the spawn noise burst.
2. In **Yin** stance, spawn an Echo in the same setup — enemies should NOT react to the spawn.
3. In **Flow** stance, spawn an Echo — no enemy reaction, Echo should replay actions smoothly.

## Slice 5 — Flow Recency Gate

**What changed:** Flow is no longer granted just by having balanced Yin/Yang. You must have performed a meaningful action (dash, attack, shuriken, teleport) within the last 2 seconds while balanced.

**Why this matters:** Idle players cannot exploit Flow bonuses. You must stay active to stay in Flow.

### Steps

1. Reach a balanced Yin/Yang state (roughly equal investment in both stances).
2. Stand completely **still** for 3+ seconds — you should lose Flow status (HarmonicStep should become unavailable; movement should not use Flow multipliers).
3. Immediately after performing a dash or attack while balanced, check that Flow IS active (HarmonicStep available, Flow movement speed applies).
4. Act, go idle for 3 seconds, act again — Flow should flicker on/off accordingly.

### Report

- [ ] Idle balance does not grant Flow.
- [ ] Active balance grants Flow.
- [ ] Flow drops off after ~2 seconds of inactivity.
- 2-second window felt too short / too long / about right:
- Any case where Flow appeared active when it shouldn't have been:

## Slice 6 — Duality Test Room

**What changed:** A dedicated 128×128 test room (`duality_test`) has been added with all the terrain types needed to stress-test the stance systems:

- Flat floor at row 112
- Three one-way platforms (rows 65, 75, 90)
- Climbable shadow-path wall (col 88)
- Raised solid blocker column for ThunderStep scenarios (col 60)

### Steps

1. If the game exposes a room-select or debug teleport, navigate to `duality_test`.
2. Verify the floor is solid (you land and don't fall through).
3. Verify the one-way platforms let you jump up through them from below and land on top.
4. Verify the climbable wall (col 88) allows wall-cling and wall-jump.
5. ThunderStep from one side of the blocker column — blocker should stop teleport (you land adjacent, not through).

### Report

- [ ] Floor is solid.
- [ ] One-way platforms work (up-through, land-on-top).
- [ ] Climbable wall works.
- [ ] Teleport respects solid blocker.
