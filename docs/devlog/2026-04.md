- **System:** Yin/Yang stance movement + duality prototype (P1-03A)
- **What changed:** Movement, traversal, and Echo abilities now express your stance. Yin play is measured and quiet — slower run, shorter dash, silent teleport, no noise on Echo spawn. - **Why it matters to players:** For the first time, picking a stance changes how you move and how the world reacts to you, not just which art you cast. A Yin run through a guard room feels different from a Yang charge — and Flow feels like genuine mastery rather than a bar to fill.
- **Suggested capture moment:** ThunderStep arrival stun on a cluster of enemies (Yang), followed by a silent Yin wall-climb escape while awareness timers tick down.
- **Confidence:** internal only (awaiting playtest validation)

- **Version:** v0.13.3
- **System:** CutsceneLoader JAR runtime fix — P0
- **What changed:** `Gdx.files.internal().isDirectory()` always returns `false` for classpath paths inside a fat JAR. The CutsceneLoader was silently bailing out and returning an empty map, so every `cutscene play <id>` call failed with `[ERR] unknown id`. Fixed by replacing directory-listing with an explicit `data/cutscenes/index.json` manifest — individual `Gdx.files.internal(path)` calls resolve correctly from the JAR classpath. Added `index.json` listing `act1_linzi_first_appearance.json`. Future cutscene files must be added to this index.
- **Why it matters to players:** The cutscene system was completely broken at runtime despite all tests passing. The fix makes `cutscene play act1_linzi_first_appearance` work correctly from the DevConsole.
- **Suggested capture moment:** DevConsole → `cutscene play act1_linzi_first_appearance` — player locks, Linzi speaks, flags set, player unlocks. Then `cutscene list` shows `[done]` state. Reload — `[done]` persists, scene does not replay.
- **Confidence:** Live smoke PASS (confirmed via launcher runtime 2026-04-29).

First Act I cutscene authored: `data/cutscenes/act1_linzi_first_appearance.json`. 36 new tests, all passing.
