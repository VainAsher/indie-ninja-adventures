# Indie Ninja Adventures — Feedback

This is the public issue tracker for **Indie Ninja Adventures** by Vain Asher Gaming.

Use this repo to report bugs, request features, or share gameplay feedback.

---

## How to Submit

Click **[New Issue](../../issues/new/choose)** and choose a template:

| Template | Use for |
|----------|---------|
| Bug Report | Crashes, broken mechanics, unexpected behaviour |
| Feature Request | Ideas for new features or improvements |
| Gameplay Feedback | How sessions felt — what worked, what didn't |
| Performance Issue | Low FPS, lag, stuttering |

**No blank issues** — please use a template so reports are actionable.

---

## What Happens to Reports

1. **Auto-labelled** on submission (bug, feature, feedback, performance)
2. **Reviewed weekly** during Monday triage
3. **Triaged** into the private pipeline as a dev task if actionable
4. **Closed** with a comment when fixed or if not reproducible

Typical response time: within 7 days. Urgent crashes may be addressed sooner.

---

## Launcher Reporting

You can submit reports directly from the launcher's **Report** tab without opening GitHub.

---

## Labels

| Label | Meaning |
|-------|---------|
| `bug` | Confirmed or reported bug |
| `feature` | Feature or enhancement request |
| `feedback` | General gameplay/UX feedback |
| `performance` | FPS, lag, or loading issues |
| `urgent` | Crash or unplayable severity |
| `multiplayer` | Affects online play |
| `ui` | Menus, HUD, launcher |
| `replay-system` | Recording or playback issues |
| `needs-triage` | Not yet reviewed |
| `needs-info` | Waiting for more details |
| `wont-fix` | Out of scope or by design |
| `duplicate` | Already reported |

---

## Code of Conduct

Be constructive. This is a solo indie project — detailed, specific reports are genuinely appreciated.
